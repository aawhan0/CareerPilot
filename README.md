# 🚀 CareerPilot — AI Career Insight Generator
[![Built with Streamlit](https://img.shields.io/badge/Built%20With-Streamlit-red)]()

---

CareerPilot is an **AI-powered career intelligence tool** that helps professionals understand how their roles evolve in an AI-driven world.

Instead of generic career advice, CareerPilot generates **role-specific insights**, including how AI will impact a job, what skills to focus on, and how to grow strategically.

Inspired by the idea of workplace intelligence platforms like **StrongYes**, this project focuses on **clarity, decision-making, and real-world career direction**.

---

## 🎯 What This Tool Does

CareerPilot takes:

- Job Role (e.g. Frontend Developer)
- Experience Level (Beginner / Intermediate / Advanced)

And generates:

- 🔮 AI Impact on the Role  
- 📈 Skills to Learn Next  
- 🧠 Career Growth Advice  
- 💰 Market Demand Insights  

---

## 🧠 How It Works

```
User Input (Role + Experience)
↓
Prompt Engineering
↓
LLM (GPT-4o-mini)
↓
Structured Career Insights
↓
Displayed via Streamlit UI

```
The system uses **prompt-driven intelligence** to generate structured and relevant outputs.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/aawhan0/CareerPilot.git
cd CareerPilot
```

Create virtual environment:

```bash
python -m venv venv
```
Activate:

Windows:
```bash
venv\Scripts\activate
```

Mac/Linux:
```bash
source venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

---

# 🔑 Setup API Key

Add your OpenAI API key in your code or use environment variables:

```
OPENAI_API_KEY=your_api_key_here

```
---

# ▶️ Run the App
streamlit run app.py

Then open:

```
http://localhost:8501

```
